# Quiz Quest

A responsive trivia quiz that fetches ten questions from the Open Trivia Database. Choose a category and difficulty, then answer each question before its 15-second timer runs out.

## Run it

Open `index.html` in a modern browser while connected to the internet. The app uses the Open Trivia Database API and saves your best score in the browser's `localStorage`.
